## Comment installer l'application ?

Suivez ces étapes, ça prend moins d'une minute :

1. **Touchez le lien de téléchargement ci-dessus.** Le fichier se télécharge (environ 4 Mo). Vous pouvez suivre la progression dans la barre de notifications.
2. **Ouvrez le fichier téléchargé.** Touchez la notification « Téléchargement terminé », ou ouvrez le fichier dans le dossier **Téléchargements** de votre téléphone.
3. **Acceptez l'installation.** Android affiche un avertissement de sécurité : c'est normal, l'application n'est pas encore sur le Play Store. Touchez **« Plus de détails »**, puis **« Installer quand même »**.
4. **Ouvrez l'application et créez votre compte.** Vous pouvez vous inscrire avec votre e-mail ou avec votre compte Google. C'est gratuit.

> **Pourquoi cet avertissement ?**
> Google vérifie toutes les applications installées hors du Play Store. MindCompta est une application de test (version bêta) : elle sera bientôt publiée sur le Play Store, et l'installation se fera alors en un seul toucher, sans avertissement.
